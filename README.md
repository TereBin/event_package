# event_package

Windows용 행사 고객 보관 키오스크 실행파일 배포 저장소입니다.

현재 배포 버전: `v2.1.0`

## 다운로드

[최신 event_package.exe 다운로드](https://github.com/TereBin/event_package/releases/latest/download/event_package.exe)

## 실행 방법

1. 위 링크에서 `event_package.exe`를 다운로드합니다.
2. 다운로드한 `event_package.exe`를 서버로 사용할 Windows 노트북에서 더블클릭합니다.
   - Windows SmartScreen이 표시되면 `추가 정보`를 누른 뒤 `실행`을 선택합니다.
   - Windows 방화벽 허용 창이 표시되면 같은 Wi-Fi의 태블릿에서 접속할 수 있도록 `개인 네트워크` 접근을 허용합니다.
3. 검은색 서버 창에서 서버 실행 비밀번호를 입력합니다. 입력 문자는 화면에 표시되지 않습니다.
4. `서비스 이름`을 입력합니다.
   - 서비스 이름은 현재 운영할 이벤트를 구분하는 이름입니다. 예: `코스앤코믹 토요일`, `코스앤코믹 일요일`.
   - 이전에 사용한 것과 동일한 이름을 입력하면 해당 서비스의 고객 데이터와 행사 설정을 이어서 사용합니다.
   - 다른 이름을 입력하면 기존 데이터와 섞이지 않는 별도 서비스로 시작합니다.
   - 같은 서비스 이름은 동시에 두 번 실행할 수 없습니다.
5. `창구 개수`를 `1`부터 `50` 사이의 숫자로 입력합니다.
   - 창구가 1개이면 고객 화면 하나가 자동으로 열립니다.
   - 창구가 2개 이상이면 서버 창에 창구별 고객 화면과 관리 화면 주소가 각각 표시되고, 서버 노트북에는 1번 창구 고객 화면이 열립니다.
6. 서버 창에 표시된 주소를 각 기기에서 엽니다.
   - `server`: 서버 노트북 전용 전체 관리자 화면입니다. 서버 노트북에서만 접속할 수 있습니다.
   - `창구 N 고객`: 고객이 이름과 연락처를 입력하는 화면입니다.
   - `창구 N 관리`: 해당 창구의 입금 대기 항목을 확인하는 화면입니다.
   - 태블릿과 다른 노트북은 서버 노트북과 같은 Wi-Fi 또는 내부 네트워크에 연결되어 있어야 합니다.

### 창구 개수 예시

창구 개수로 `2`를 입력하면 서버 창에 다음과 같은 주소가 표시됩니다. 실제 IP 주소와 포트는 실행 환경에 따라 달라집니다.

```text
server: http://127.0.0.1:8000/admin.html
창구 1 고객: http://192.168.0.10:8000/customer.html?counter=1
창구 1 관리: http://192.168.0.10:8000/manager.html?counter=1
창구 2 고객: http://192.168.0.10:8000/customer.html?counter=2
창구 2 관리: http://192.168.0.10:8000/manager.html?counter=2
```

각 창구에서 접수된 입금 대기 항목은 해당 창구 관리 화면에만 표시됩니다. 입금 확인이 끝난 항목은 모든 관리 화면에 표시됩니다.

### 여러 이벤트를 동시에 실행하는 경우

1. 첫 번째 `event_package.exe`를 실행하고 첫 번째 서비스 이름과 창구 개수를 입력합니다.
2. `event_package.exe`를 한 번 더 실행하고 다른 서비스 이름을 입력합니다.
3. 첫 번째 서비스가 `8000` 포트를 사용 중이면 두 번째 서비스는 `8001`, 세 번째 서비스는 `8002`처럼 사용 가능한 포트를 자동으로 선택합니다.
4. 각 서버 창에 표시된 주소를 구분해 해당 이벤트 기기에 전달합니다.
5. 실행 중인 서비스마다 서버 창을 닫지 않고 유지합니다.

예를 들어 `행사 A`와 `행사 B`를 동시에 실행해도 고객 데이터, 행사 설정, 로그는 서비스별 폴더에 따로 저장됩니다. 같은 서비스 이름으로 중복 실행하면 기존 서버를 먼저 종료하라는 메시지가 표시됩니다.

### 종료와 업데이트

- 서버를 종료하려면 해당 서비스의 검은색 서버 창에서 `Ctrl+C`를 누르거나 창을 닫습니다.
- 새 버전으로 업데이트할 때는 최신 `event_package.exe`를 다시 다운로드해 실행하면 됩니다.
- 실행파일의 저장 위치나 이름을 바꿔도 기존 고객 데이터와 행사 설정은 유지됩니다.

별도 설치 파일이나 설정 파일은 필요하지 않습니다. 고객 데이터와 로그는 Windows 사용자 로컬 앱 데이터 폴더에 보존되므로 새 버전의 실행파일로 교체해도 유지됩니다.

## 주요 기능

- 고객 접수와 입금 확인, 보관·수령 상태 관리
- 1~50개 창구 운영과 창구별 입금 대기 항목 분리
- 서버 전체 관리자와 창구 관리자의 기능·접근 권한 분리
- 서비스 이름별 고객 데이터와 행사 설정 분리
- 여러 서비스를 동시에 실행할 때 사용 가능한 포트 자동 선택
- 스태프 화면에서 행사명, 안내 문구, 계좌 및 자동 결번 설정
- 고객 목록 CSV 내보내기와 불러오기
- 새 실행파일로 업데이트해도 로컬 행사 설정과 고객 데이터 유지
